# قائمة اليوم الأول — لوحة إدارة Shubayr

اطبع هذه الصفحة وأشّر على كل خطوة عند إنجازها. التفاصيل والصور في [دليل البدء السريع](ar.md).

**ما تحتاجه قبل البدء:** رابط لوحة الإدارة · اسم المستخدم وكلمة المرور المؤقتة · رابط معاينة المتجر (إن كان المتجر «يفتح قريبًا») · قائمة منتجاتك وصورها وأسعارها وكمياتها وكلفتها.

| ✓ | الخطوة | أين | ملاحظات |
|---|---|---|---|
| ☐ | الدخول وتغيير كلمة المرور المؤقتة | صفحة الدخول | |
| ☐ | اسم المتجر وساعات العمل والإعدادات العامة | إعدادات المتجر | |
| ☐ | مناطق التوصيل ورسومها؛ لا يبقى تحذير لمحافظة تريد التوصيل إليها | مناطق التوصيل | |
| ☐ | الأقسام الرئيسية وأقسامها الفرعية | الأقسام | |
| ☐ | العلامات التجارية | العلامات التجارية | |
| ☐ | أول منتج كامل: صور، أنواع، سعر، «ظاهر في المتجر» | المنتجات ← منتج جديد | |
| ☐ | المخزون الافتتاحي لكل منتج (الكمية وكلفة الوحدة) | صفحة المنتج ← الرصيد الافتتاحي | |
| ☐ | باقي المنتجات (استخدم «نسخ المنتج» للمتشابهة) | المنتجات | |
| ☐ | الخصومات التلقائية (اختياري) | الخصومات التلقائية | |
| ☐ | حسابات الموظفين وصلاحياتهم | الموظفون | |
| ☐ | معاينة المتجر من رابط المعاينة: الصور والأسعار والتوصيل | المتجر | |
| ☐ | طلب تجريبي من المتجر، ثم تأكيده بعد الاتصال بالزبون | الطلبات | |

**تذكير يومي**

- ☐ اتصل بكل زبون قبل تأكيد طلبه، واكتب ملاحظة الاتصال.
- ☐ غيّر رسوم التوصيل عند التأكيد فقط مع سبب واضح.
- ☐ راجع المنتجات «نفد المخزون» و«مخزون منخفض» في قائمة المنتجات.
